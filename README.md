# Personal Portfolio Website

A modern and responsive portfolio website built using HTML, CSS, JavaScript, and Tailwind CSS. The website showcases my skills, projects, education, experience, and contact information through an interactive and visually appealing user interface.

## Features
- Responsive Design
- Animated Hero Section
- Skills Showcase
- Project Portfolio
- Experience & Education Timeline
- Contact Form
- Social Media Integration
- Smooth Scrolling & Animations

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome
- Google Fonts
